# Төсөлд заалтын харьцуулалт нэмэх

`/bills` дээрх төслүүдээс одоогоор зөвхөн **демо төсөл** (автозогсоолын татвар) заалт бүрийн
харьцуулалттай. Бусад төсөлд харьцуулалт нэмэхэд хоёр текст хэрэгтэй:

| Текст | Хаанаас | Автоматаар татагддаг уу |
| --- | --- | --- |
| **Төслийн эх бичвэр** | lawforum.parliament.mn-ийн төслийн хуудас | ✅ тийм (`scripts/add-comparison.ts` өөрөө татна) |
| **Хүчин төгөлдөр хуулийн нэгдсэн эх** | legalinfo.mn | ❌ үгүй — гараар хуулж авна |

## Яагаад хуулийн текстийг гараар хуулах ёстой вэ

- legalinfo.mn нь хуулийн биетийг зөвхөн хөтөч дээр (JavaScript-ээр) ачаалдаг. `curl`, скриптээр
  татахад зөвхөн хуудасны хүрээ ирдэг — хуулийн текст ирдэггүй (cookie, User-Agent сольж үзсэн).
- parliament.mn дээрх хуулийн эмхэтгэл PDF-үүд татагддаг **боловч хуучирсан**. Жишээ:
  2019 оны эмхэтгэлийн ААНОАТ-ын 21.1.1 нь "Засгийн газар, Монгол Улсын Хөгжлийн банкны…" гэсэн бол
  төсөл (lawforum 11057) "Засгийн газар, **Нийслэл**, Монгол Улсын Хөгжлийн банкны бондын хүү" гэж
  иш татаж байна — өөрөөр хэлбэл хууль хожим өөрчлөгдсөн. Хуучин эхээр харьцуулбал **буруу**
  "Одоо" текст гарна. Тиймээс хуучин эмхэтгэлийг ашиглахгүй.

## Алхам (нэг төсөлд ~2 минут)

1. legalinfo.mn дээр тухайн **хүчин төгөлдөр** хуулийг хөтчөөр нээ (жишээ нь "Аж ахуйн нэгжийн
   орлогын албан татварын тухай /Шинэчилсэн найруулга/").
2. Хуулийн бүх текстийг сонгоод хуулж аваад `data/laws/<төслийн key>.txt` файлд хадгал
   (жишээ нь `data/laws/lf-11057.txt`). Төслийн key-г `data/precomputed.json`-оос хар.
3. Ажиллуул:

   ```
   npx tsx --env-file=.env scripts/add-comparison.ts --bill=lf-11057 --law=data/laws/lf-11057.txt
   npm run seed
   ```

4. Шалга: `/bills/seed-lf-11057` дээр заалт бүрийн "Одоо / Болох нь" харьцуулалт, тодорсон үгс.

## Аюулгүйн шалгалт

Төсөл иш татсан үг хуулийн текстээс олдохгүй бол скрипт тухайн заалтыг **"тулгагдсангүй"** гэж
мэдээлээд юу ч бичихгүй (`--force` гэж албадаж болох ч БҮҮ хий). Энэ нь хуулийн хуучин хувилбар
өгсөн гэсэн шинж — питч дээр "тодорсон үг бүр яг эх бичвэрийнх" гэж хэлдэг тул буруу
харьцуулалт гаргахаас сэргийлнэ.

## Юу автоматаар болдог вэ

`readAmendment` (AI) → төслийг өөрчлөлтийн жагсаалт болгоно → `applyChanges` (код) → хуулийн заалтад
хэрэгжүүлнэ → `compareWords` (код) → үг тутмын ялгаа → `explainChange` (AI) → "Юу / Яагаад / Хэнд"
энгийн тайлбар. Үр дүн `data/precomputed.json`-д хадгалагдана, `npm run seed` DB рүү оруулна —
демогийн үед AI огт дуудагдахгүй.
