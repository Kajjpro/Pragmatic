# Демо сэргээх — питчийн өмнөх шалгах хуудас

Питчийн өмнө болон бэлтгэл бүрийн дараа энэ дарааллаар хийнэ. AI огт дуудагдахгүй.

## 0. Нэг удаа тохируулах (`.env`)

```
DATABASE_URL=<production DB>
DEMO_CITIZEN_EMAIL=<демо иргэний Google имэйл>
DEMO_CITIZEN_COMMENT=<багийн гишүүний бодит санал — демо дээр "Тусгасан" болно>
STAFF_EMAILS=<ажилтны имэйл>
```

## 1. Өгөгдөл (зөвхөн `data/precomputed.json` шинэчлэгдсэн бол)

```
git pull origin main
npx prisma migrate deploy
npm run seed
```

Хүснэгтэд карт 10+, бүлэг, санал хураалт гарсан эсэх, анхааруулга байгаа эсэхийг хар.

## 2. Демог сэргээх (питч бүрийн өмнө)

```
npm run reset-demo
```

- Демо иргэн: оноо **2**, streak **0**, тэмдэггүй, таамаггүй, мэдэгдэлгүй
- Демо төслийн бүлгүүд: хариугүй, "Хүлээгдэж буй"
- Replay санал хураалт: дахин **OPEN**, бусдын авсан таамгийн оноог буцааж хасна
- Демо бүртгэлээр бэлтгэлийн үеэр бичсэн нэмэлт санал устана (seed-ийн демо санал үлдэнэ)
- Төгсгөлд **"✓ Демо бэлэн"** гарах ёстой. ⚠ гарвал доорх "Асуудал гарвал" хэсгийг хар.

## 3. Санал хураалт бэлэн эсэх

```
npm run vote -- list
```

Replay санал хураалт: Төлөв **OPEN**, Replay **тийм**, Нууц тоо **бий** байх ёстой.
"Нууц тоо алга" бол: `npm run vote -- sync` (ParliamentAPI хэрэгтэй).

## 4. Төхөөрөмж бэлдэх

- [ ] **Зочин**: хөтчийн нууц цонх (private) — өмнөх явц (localStorage) үлдээгүй
- [ ] **Демо иргэн** (утас): `DEMO_CITIZEN_EMAIL`-ээр нэвтэрсэн
- [ ] **Ажилтан** (зөөврийн компьютер): `STAFF_EMAILS`-ийн имэйлээр нэвтэрсэн, `/staff` нээлттэй
- [ ] `BASE_URL=https://<prod> npm run smoke` → бүгд ✓
- [ ] Нөөц видео бичлэг бэлэн

## 5. Демогийн дараалал

1. **Зочин**: `/` → `/feed` (Сурагч) → 3 карт → асуулт → хадгалах үед нэвтрэхийг санал болгоно
2. **Демо иргэн**: оноо, streak нэмэгдэнэ → `/predict` дээр replay санал хураалтад таамаг → `/me`
3. **Ажилтан**: `/staff` → демо төсөл → "Санал бүлэглэх" (бэлэн бүлгүүд, AI хүлээхгүй) → демо иргэний санал орсон бүлэгт **"Тусгасан"**
4. **Демо иргэн**: мэдэгдэл → "Хууль өөрчилсөн иргэн" тэмдэг → `/b/[id]` → хуваалцах зураг
5. **Ажилтан**: replay санал хураалтын дүнг зарлана → иргэнд оноо

   Ажилтны дэлгэцэнд товч байхгүй эсвэл алдаа гарвал нөөц арга:
   ```
   npm run vote -- reveal <agendaCode>
   ```

## Асуудал гарвал

| Шинж тэмдэг | Шийдэл |
|---|---|
| "Демо иргэний санал алга" | `.env`-д `DEMO_CITIZEN_COMMENT` бичээд `npm run seed`, дараа нь `npm run reset-demo` |
| "хэрэглэгч алга" | `npm run seed` (демо иргэнийг үүсгэнэ; анх нэвтрэхэд тэр бүртгэлийг өөрийнх болгоно) |
| Санал хураалт "Нууц тоо алга" | `npm run vote -- sync` эсвэл Dev 2-ийн `data/precomputed.json`-д санал хураалт байгаа эсэх |
| ParliamentAPI алдаа (503) | Сайт хэвийн ажиллана. Replay-ийн нууц тоо бий бол reveal API-гүй ажиллана |
| Бүх зүйл эвдэрсэн | `npm run seed` → `npm run reset-demo` (seed дахин ажиллуулж болно, давхардахгүй) |
